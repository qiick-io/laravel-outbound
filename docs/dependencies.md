# Dependency register

Every runtime entry from the root `composer.json` `require` object is listed
below; `require-dev` is not. The register is reviewed at every release and in
every PR that changes `require`.

| Dependency                    | Version constraint | Why this minimum                                                                                          | What we use                                                                                                                     | What we replace or extend and why                                                                                 | Maintainer                     | License                            | Known risk                                                                            | Exit plan within this package                                                     |
| ----------------------------- | ------------------ | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------ | ---------------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `php`                         | `^8.3`             | Floor set at the scaffold (#1); the CI matrix runs 8.3–8.5 and readonly classes/enums need 8.1+. Laravel 12/13 would allow 8.2, so the floor is this package's own choice. | Language runtime: readonly classes, enums, `str_ends_with`, first-class callables in `src/`.                                    | Nothing to replace; platform requirement.                                                                        | PHP Group                      | PHP-3.01                           | None known.                                                                           | Not replaceable; the floor is raised deliberately per release.                   |
| `ext-curl`                    | `*`                | Any curl handler; Guzzle falls back to other handlers, but pinning is curl-only.                          | `CURLOPT_CONNECT_TO` / `CURLOPT_NOPROXY` / `CURLOPT_HTTPPROXYTUNNEL` constants and option arrays in `src/Http/PinnedHttpClient.php` and `src/Ssrf/`. | Extends Guzzle's curl handler with fixed options; the SSRF pin (`CONNECT_TO`, never `RESOLVE`) needs raw curl options. | PHP project                    | PHP-3.01 (libcurl MIT)             | Option constants depend on the linked libcurl version; a host without curl fails at boot via `CURLOPT_CONNECT_TO` check. | Not replaceable without re-implementing the transport; swap to another handler only if it supports the same options. |
| `ext-intl`                    | `*`                | Any ICU-backed intl; UTS46 IDNA is the only normalization that matches browser/curl hostname handling.      | `idn_to_ascii(..., IDNA_NONTRANSITIONAL_TO_ASCII, INTL_IDNA_VARIANT_UTS46)` in `src/Ssrf/RemoteUrlGuard.php` for hostname canonicalization before SSRF checks. | Extends the URL guard: without UTS46 normalization, full-width digits/punctuation and ideographic dots could mint IP-like hostnames past the blocklist. | PHP project (ICU upstream)     | PHP-3.01 (ICU)                     | IDNA results can differ across ICU versions shipped by different OSes.                  | Replace `idn_to_ascii` with a pinned IDNA library (e.g. a UTS46 implementation in PHP) if ICU drift is observed. |
| `ext-mbstring`                | `*`                | Any mbstring; all uses are byte/UTF-8 safe string cuts and validation.                                     | `mb_scrub`, `mb_substr`, `mb_strcut`, `mb_check_encoding` in `src/Delivery/DeliveryAttempt.php`, `src/Webhooks/WebhookMessage.php`, `src/Delivery/WebhookDeliveryCoordinator.php`. | Nothing to replace; platform requirement for safe UTF-8 handling of error strings and webhook ids.               | PHP project                    | PHP-3.01                           | None known.                                                                           | Replace `mb_*` calls with `symfony/polyfill-mbstring` or plain `substr` only if semantics are re-verified. |
| `guzzlehttp/guzzle`           | `^7.12 \|\| ^8.0`  | 7.12 is the first 7.x that sets `CURLOPT_NOPROXY`; older 7.x let `NO_PROXY` bypass the egress proxy (#39).   | `GuzzleHttp\Handler\CurlHandler`, `GuzzleHttp\Exception\GuzzleException`, `GuzzleHttp\Psr7\Uri` / `UriResolver` and the Laravel HTTP client built on it in `src/Http/PinnedHttpClient.php`; `PendingRequest` curl options. | Extends Guzzle's handler stack and PSR-7 URIs rather than wrapping a second HTTP client, so redirects, proxies and TLS stay in one transport. | Community (GuzzleHttp org)    | MIT                                | Two supported majors (7 and 8) double the curl-errno and option handling surface; Packagist advisories have blocked older 7.x installs in CI. | Drop the 7.x line once Laravel no longer resolves it; then port any remaining 7-only branches and remove the dual-version tests. |
| `illuminate/contracts`       | `^12.0 \|\| ^13.0` | Matches the two supported Laravel majors; contracts are what the package actually depends on.              | `Illuminate\Contracts\Events\Dispatcher`, `Debug\ExceptionHandler`, `Config\Repository`, `Cache\Repository`, `Queue\ShouldQueue`, `Foundation\Application` across `src/Laravel`, `src/Delivery`, `src/Listeners`. | Nothing to replace; depending on contracts instead of `laravel/framework` keeps the package installable inside any Laravel app without dragging the whole framework. | Laravel (Taylor Otwell)        | MIT                                | The component is `replace`d by `laravel/framework` in apps; a version floor here must stay in lockstep with the app's framework major. | If contracts diverge from the framework, pin to `laravel/framework` in dev only and re-split when upstream stabilizes. |
| `illuminate/database`        | `^12.0 \|\| ^13.0` | Added for the five package webhook tables (#19); same major range as the rest of `illuminate/*`.             | Eloquent `Model`, relations, `SoftDeletes`, `HasUuids`, `Builder`, `Collection`; `DetectsConcurrencyErrors`, `DeadlockException`, `UniqueConstraintViolationException`; migrations and `Schema` in `src/Laravel/OutboundServiceProvider.php`. | Extends the app's database layer with package-owned tables and models instead of asking products to write their own schema — one domain for every surface. | Laravel (Taylor Otwell)        | MIT                                | Ties the package to Eloquent semantics (casts, encrypted casts, mass-assignment); a product on a different DB layer cannot use the delivery store. | Extract a `DeliveryStore` contract implementation per driver if a non-Eloquent product ever needs the package. |
| `illuminate/http`            | `^12.0 \|\| ^13.0` | Laravel HTTP client wrapper; same major range as `illuminate/*`.                                             | `Illuminate\Http\Client\Factory` / `PendingRequest` / `Response` / `ConnectionException` consumed by `src/Http/PinnedHttpClient.php` to attach curl options and read transport errors. | Extends the Laravel HTTP client (which itself wraps Guzzle) so products keep `Http::` fakes and macros while the package injects SSRF guards. | Laravel (Taylor Otwell)        | MIT                                | The client API is not a stability contract across majors; option-array internals (`PendingRequest::$options`) are reached via reflection. | Port `PinnedHttpClient` to the PSR-18 client Laravel exposes, or pin the inspected option path per Laravel major. |
| `illuminate/notifications`   | `^12.0 \|\| ^13.0` | Added for auto-disable owner notification (#31); same major range as `illuminate/*`.                         | `Notification`, `Notifiable`, `Queueable` / `ShouldQueue`, `MailMessage` in `src/Notifications/WebhookEndpointDisabledNotification.php` and `src/Listeners/NotifyWebhookEndpointOwnerListener.php`. | Extends the app's notification stack so the auto-disable email uses the product's mailer, queue and localization instead of a bespoke sender. | Laravel (Taylor Otwell)        | MIT                                | Requires the product's user model to use `Notifiable`; a product without notifications configured gets silent or failed sends. | Swap `WebhookEndpointDisabledNotification` for an event-only contract and let products implement delivery. |
| `illuminate/support`         | `^12.0 \|\| ^13.0` | Foundation helpers, service provider base and facades; same major range as `illuminate/*`.                   | `ServiceProvider` (`src/Laravel/OutboundServiceProvider.php`), facades (`Http`, `DB`, `Schema`, `Event`, `Notification`), `Str`, `Collection`, `Carbon`/`CarbonImmutable` across `src/`. | Nothing to replace; the package is a Laravel package and uses the framework's own helpers rather than duplicating them. | Laravel (Taylor Otwell)        | MIT                                | Facade and helper APIs shift between majors; the `^12 \|\| ^13` range must be re-verified on each new major. | Inline the few helpers used (collections, `Str`) if a future major breaks them; they are a thin surface. |
