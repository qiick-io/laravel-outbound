# Security checklist: properties and the tests that cover them

Each security property of the package names the test that fails when the property breaks, so the 1.0 checklist ("every security item has a red-first test that names it") can be checked line by line. **Gap** marks a property with no test, **Partial** one whose test covers only part of it. O1–O23 are the design's security table (design §5); S-rows are the package's own. The full release mutation gate checks every PHP file in `src/` against the per-file 95% floor, including shipped fakes (#102).
